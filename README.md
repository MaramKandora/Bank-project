# Bank System & Currency Exchange (OOP)

This project is a console-based Bank System built in C++ using Object-Oriented Programming, extended with a Currency Exchange module. It demonstrates how a core system can be expanded by integrating new features in a modular and scalable way.

# Key Features

- Manage bank system operations
- Currency exchange subsystem with:
   - List currencies
   - Search by country or code
   - Update exchange rates
   - Convert between currencies

# Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File handling for data storage
- Console-based interface (CLI)

# Learning Goal

The project focuses on applying core OOP principles, modular design, and real-world system expansion.
